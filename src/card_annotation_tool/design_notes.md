# key binds
| Action           | Key             | Description        |
| ---------------- | --------------- | ------------------ |
| Confirm / Next   | `Enter (13)`    | Validate & save    |
| Undo             | `Backspace (8)` | Remove last point  |
| Skip             | `Esc (27)`      | Skip current image |
| Quit             | `Q`             | End program        |
| Reset (optional) | `R`             | Clear all corners  |
